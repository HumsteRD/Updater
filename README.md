# Updater

Программа, которая превращает переустановку Windows из «двух вечеров настройки» в одну кнопку.
На старой винде собирает всё нужное на флешку или другой диск — вместе с собой, — а на новой
возвращает всё на место.

## Как пользоваться

1. **Старая винда:** запусти `Updater.exe` → «Начать сборы». Программа сама найдёт папки,
   программы, их настройки, сохранения игр и настройки Windows, покажет размеры. Выбери флешку
   или диск (не C:) и нажми «Собрать». В папке `Updater` окажутся вещи и сама программа (`Updater.exe`).
2. **Переустанови Windows**, не трогая диск со сборкой.
3. **Новая винда:** запусти `Updater.exe` из сборки → «Распаковать» → «Начать переезд».
   Драйверы встают первыми, программы ставятся через winget (или с флешки, если интернета ещё нет),
   файлы копируются одновременно с ними, потом настраивается Windows (как было, по рекомендациям
   или выборочно; всё можно откатить).

## Что переносится

| Раздел | Что именно |
|---|---|
| Файлы | Рабочий стол, Документы, Загрузки, Изображения, Видео, Музыка, свои папки в профиле, **папки в корне C:** (их сотрёт переустановка), любые папки вручную |
| Программы | Список установленного; ≈3/4 программ встают сами через winget (встроенный индекс сопоставляет даже без winget на старом ПК), остальные — ссылками; набор библиотек для игр (VC++, DirectX, .NET, XNA); популярные программы на выбор. **Установщики на флешку** (по желанию): официальные установщики браузера, Steam, Discord, Telegram и др. скачиваются на флешку заранее и ставятся на новой винде даже без интернета или без winget |
| Настройки программ | ≈60 программ, показываются только установленные. **Главное** отмечено сразу: браузеры (закладки, расширения, вкладки), Telegram/AyuGram (вход сохраняется), Steam и другие игровые клиенты, OBS, Office (шаблон Normal, подписи Outlook, словарь), Afterburner, VS Code, Git/SSH, VPN-клиенты… **По желанию** — не отмечено: мелкие настройки утилит (Everything, 7-Zip, ShareX, qBittorrent…) и тяжёлые истории ИИ-инструментов — их легко выставить заново |
| Сохранения игр | «Сохранённые игры», My Games, Unity (LocalLow), Unreal (LocalAppData\…\Saved), каталог игр в других местах, конфиги Dota 2/CS2 |
| Windows | 55 настроек (тема, акцент, обои, панель задач, Проводник, «Пуск», мышь, раскладки, игровой режим, реклама, часовой пояс, электропитание, PATH…), драйверы, сети Wi‑Fi с паролями, шрифты, hosts, закреплённое в «Пуске», на панели задач и в Проводнике |
| Перед переустановкой | Напоминания: пароли браузеров, ключи BitLocker, игры Steam на C:, активация |

Честно о том, что **не** переносится: пароли и **входы на сайты (куки)** в Chromium-браузерах
(Chrome/Brave/Edge и т. п. с 2024 года шифруют их под конкретный ПК — нужна синхронизация или
экспорт паролей; у **Firefox** куки и логины переезжают сами), вход в Discord, приложения Store
(открываются их страницы), игры, установленные на C: (Steam скачает заново — программа предупредит).

## Устройство сборки

- `Файлы/…` — папки как есть, файл в файл: забрать можно и без программы. На FAT32 файлы > 4 ГБ
  режутся на части `имя.__part001…` и склеиваются при распаковке.
- `Программы/*.zip`, `Игры/*.zip` — настройки и сейвы, по архиву на пункт (мелкие файлы на флешку
  так пишутся в разы быстрее). Большие пункты (> 2 ГБ) — папкой, чтобы работала докачка.
- `Программы/Установщики/` — официальные установщики, если их скачали.
- `Windows/` — обои, драйверы (пакеты из DriverStore), Wi‑Fi, шрифты, схема питания.
- `updater.json` — опись; пути хранятся метками (`{AppData}\…`), поэтому другое имя
  пользователя на новой винде не мешает. Сборки прежних версий (папка `Переезд`, `pereezd.json`)
  тоже открываются.
- Сборы можно прерывать и запускать снова в ту же папку — скопированное не копируется повторно.

## Разработка

Нужен .NET 9 SDK (подойдёт локальный из VELOCITY: `D:\Projects\Velocity\.tools\dotnet\dotnet.exe`).

```bash
dotnet build Updater.sln
dotnet run --project tests/Updater.SelfCheck              # проверки в песочнице (≈130)
dotnet run --project tests/Updater.SelfCheck -- --live    # плюс живой скан этого ПК (только чтение)
dotnet publish src/Updater.App -c Release -o publish      # один Updater.exe ≈59 МБ, .NET внутри
```

Снимки экранов без запуска действий: `Updater.exe --shot collect out.png --section 2`
(`home`, `collect`, `collect-progress`, `collect-done`, `restore`, `restore-progress`, `restore-done`;
для распаковки нужен `--package <папка сборки>`). Тестовая сборка из несекретных мелочей этого ПК:
`dotnet run --project tests/Updater.SelfCheck -- --demo-package <папка> [--include ids] [--installers ids]`.

Самопроверка пишет только во временную папку и в ветку реестра `HKCU\Software\Updater.SelfCheck`,
которую удаляет; настоящие настройки только читает.

### Проверка распаковки на чистой Windows

`Updater.exe --auto-restore <папка результатов> [--programs id1,id2] [--settings was|recommended|none] [--no-winget]`
проходит распаковку без человека (экран плана → «Начать переезд» → прогресс → итог), снимает каждый
экран и сверяет результат: файлы на местах, программы в «Программах и компонентах», значения настроек.
В папке результатов: `verify.txt`, `journal.txt`, снимки `*.png`. `--no-winget` проверяет установку
с флешки без интернета.

- **Windows Sandbox** (нужны SVM/VT-x в BIOS, компонент «Песочница Windows» и запущенный
  гипервизор — `bcdedit /set hypervisorlaunchtype auto`):
  `powershell -ExecutionPolicy Bypass -File tools\sandbox-test.ps1` — соберёт тестовую сборку
  из несекретных мелочей этого ПК (с установщиками Steam и Visual C++), запустит песочницу и дождётся
  `verify.txt`. По умолчанию проверяет установку с флешки без интернета; с `-UseWinget` — настоящий путь:
  Updater сам ставит winget (в песочнице его нет) и через него программы из `-Programs`.
- **Безопасно на рабочем ПК:** добавь `--sandbox-root <временная папка> --offscreen` — пути уйдут во
  временную папку, реестр — в `HKCU\Software\Updater.AutoTest` (удаляется), программы, драйверы и
  системные настройки пропускаются.

- `src/Updater.Core` — вся логика: скан, сборы, распаковка, winget, настройки Windows.
  Каталоги — данные: `Catalog/apps.json`, `games.json`, `windows.json`, `programs.json`, `installers.json`.
- `src/Updater.App` — WPF, тема «Графит» из VELOCITY/FI.
- `tools/build-winget-index.py` — обновление встроенного индекса winget
  (`https://cdn.winget.microsoft.com/cache/source2.msix` → `Public/index.db`).
